# Matin Resume Recovery Harness

Zero-cost, independent GitHub-hosted recovery validation for the private `MST32H/matin-resume` repository.

This public repository contains only generic recovery validation tooling and policies. It does **not** contain the resume site's private source, production credentials, recovery payloads, or personal data.

Recovery payloads are read at runtime from the existing private S3-compatible recovery store through GitHub Actions secrets.
